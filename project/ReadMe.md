# 加点項目
* ローダーと配置
* コライダーをゲーム側当たり判定に適用
* SpawnPoint（敵などの発生地点）の配置
* イベントトリガーの配置
* ギミックの配置
* カメラの配置
* Terrain（地形）の配置

# 独自実装
* 破壊可能（Destructible）フラグや敵の詳細パラメータ（行動パターン、陣形など）のプロパティ追加
  * デフォルトのリストにないゲーム向けのカスタム設定項目を追加
* AIを活用した地形とレールの自動生成機能
  * Google Gemini APIを使用し、テキストプロンプトから地形構成を自動算出する
* 地形カテゴリごとのプロファイル成形とシームレス結合
  * A.N.T.Landscapeと連携し、前後で異なる地形（山や海など）を違和感なく繋ぐフェード処理を実装した
* 遠景モデル（背景山脈）の自動生成
  * メイン地形の外側を覆う巨大な背景山脈を自動で生成し配置する
* ゲーム内視界（フラスタム）の可視化
  * ゲームと同じFOVのカメラと、奥までの視界枠をワイヤーフレームで自動生成する
* OBJの一括出力機能 (カスタムメニュー)
  * シーン内の複数のメッシュオブジェクトを、一度に別々のOBJファイルとして自動エクスポートするメニューを追加
* APIとの非同期通信とUIエラーハンドリング
  * Blenderをフリーズさせないための別スレッド通信や、通信エラーをポップアップで知らせる仕組みを構築
* 自動生成地形のUV自動計算と展開
  * ゲームエンジン側でテクスチャが綺麗にタイリングされるよう、生成したメッシュの頂点座標からUVを自動計算して書き込む処理
* 親子階層構造の再帰的エクスポート
  * Blender上のオブジェクトの親子関係を解析し、ツリー構造を維持したままJSONへ出力するアルゴリズム
* エディタ向けの独自UIパネル構築
  * プロパティウィンドウに専用パネルを作成し、コライダー形状や敵のAIパラメータを直感的に設定できるUIを実装
